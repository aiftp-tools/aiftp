### 実測で判明した躓きポイント（研修手順書に反映する）

1. **host 誤記は TLS 段階まで検出されない** — `.aiftp.toml` の host を `stars.ne.jp` と誤記→証明書 `*.star.ne.jp` と不一致で push が TLS で失敗。**合言葉承認は通過した後に落ちる**ため原因が分かりにくい。`aiftp_profile_test`（読み取り専用・合言葉不要）を先に回せば push 前に検出できる
2. **`aiftp backup init --profile <name>` はサイト×プロファイル単位で必要** — `setup_status` は FTP 認証情報しか見ないため、backup 鍵未初期化でも pass のまま通過する。ターミナル必須の手順が Desktop 導線に1つだけ残るのは矛盾（→ v0.13.1 候補: bootstrap で自動初期化）
